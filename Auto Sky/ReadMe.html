Auto Sky is an After Effects template. You can open the .aep file in After Effects, version 2023 or later. You can also import the Auto Sky project into your existing project by going to File > Import > File.

This sky effect was developed the "Landscaper" template, which allows users to create stunning 3D landscape animations in After Effects. Watch the Landscaper demo on YouTube.
